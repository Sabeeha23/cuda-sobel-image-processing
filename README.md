# CUDA-Based Sobel Image Processing

## Project Description

This project implements Sobel edge detection using NVIDIA CUDA and OpenCV. The CUDA kernel performs parallel image processing on the GPU. A dataset of 120 images was processed, and the resulting edge-detected images were saved in the output folder.

## Objective

To demonstrate GPU-accelerated image processing using CUDA and parallel pixel processing.

## Technologies Used

NVIDIA CUDA, C++, OpenCV, NVIDIA Tesla T4 GPU, Google Colab.

## Dataset

120 input images were generated and processed.

## Results

All 120 images were successfully processed and 120 Sobel output images were generated.

## CUDA Configuration

The program uses a 16 x 16 CUDA thread block configuration.
